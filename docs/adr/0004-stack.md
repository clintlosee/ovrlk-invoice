# Stack: TanStack Start, Drizzle, Turso, Better Auth on Render

TanStack Start (React) with shadcn/ui and Tailwind, Drizzle ORM on Turso (libSQL), Better Auth, Resend for email, Cloudflare R2 for files, hosted on Render. The owner knows Nuxt well and picked TanStack Start to learn React; the data and auth layers stay on tools he already uses to keep the new surface small.

Considered: Nuxt + Nuxt UI (faster for the owner, no learning value).
